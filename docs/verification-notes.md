# 화면 검증 기록

## 2026-08-18: 대관 확인·프로그램 안내 단순화

데스크톱(1280×720) 전체 화면에서 `booking.html`은 신청서·시간표 탭 없이 **대관 확인** 제목, 캘린더, 대관 일정 상태 안내만 표시되는 것을 확인했다. `programs` 화면은 기존의 `문화로 만나는 이번의 시간` 제목과 소개 문단 없이 프로그램 필터와 목록·달력 전환부터 바로 시작되는 것을 확인했다.

모바일(375×812)에서도 대관 캘린더는 단일 영역으로 표시됐고, 프로그램 안내는 제거 요청된 제목·설명 없이 필터와 목록·달력 제어를 세로로 배치해 가로 스크롤 없이 확인했다.

GitHub 저장소의 Pages 설정은 아직 비활성 상태여서, 이전 정적 배포 작업은 Pages 배포 생성 단계에서 404로 실패했다. Pages 활성화와 Apps Script 재배포가 끝난 뒤에는 GitHub Pages 실제 주소에서 대관 데이터·프로그램 데이터·관리자 사진 업로드를 다시 확인해야 한다.
